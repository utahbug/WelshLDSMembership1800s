Welsh names and spelling

Welsh place names may appear with different first letters because Welsh grammar can change the opening consonant of a word. For example, a name beginning with C may appear with G in some contexts. Historical spelling, anglicized forms, and transcription or OCR differences can also create variants.

This site preserves these source forms and links them to the same place when the evidence supports that relationship.
