# Offline CD image location

Place the preserved CD image folders here:

`C:\Users\kenro\Documents\Codex\LDSWelshMembers\records\source-cds\`

Use one folder per disc:

- `CD 01`
- `CD 02`
- continuing through `CD 62`

The `records/source-cds` directory is intentionally excluded from GitHub because the original images are large. It remains part of the local and flash-drive editions. The public catalog retains collection metadata even when images are not yet online. A future collection can set `publicStorage.provider` to `internet-archive`, supply an Internet Archive item identifier and `baseUrl`, and keep the authoritative filenames and page order in this catalog.

Recovered full-resolution images are now stored directly beneath `records/source-cds`, preserving their collection-folder names. Typed transcription PDFs are stored directly in `records/transcriptions` so the same files can be opened by the local viewer and GitHub Pages. Thumbnail images and obsolete CD-player support files remain in the recovery source folder and are not part of the viewer catalog.
